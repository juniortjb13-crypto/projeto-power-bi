# 📊 Projeto de Análise de Dados com Power BI

Projeto acadêmico desenvolvido durante os estudos de Análise e Desenvolvimento de Sistemas, com o objetivo de aplicar técnicas de tratamento, modelagem e análise de dados utilizando o Microsoft Power BI.

## 📌 Sobre o projeto

O projeto consiste na análise de dados de vendas utilizando o Power BI, trabalhando com tratamento e transformação dos dados, criação de relacionamentos, medidas e construção de dashboards para facilitar a interpretação das informações.

A base principal utilizada foi o conjunto de dados **Superstore**, complementado por uma base de **metas**, permitindo realizar análises de vendas, lucro, regiões e comparação com metas estabelecidas.

## 🛠️ Tecnologias e ferramentas utilizadas

- Microsoft Power BI
- Power Query
- Linguagem M
- DAX
- Microsoft Excel
- Modelagem de dados

## 🔄 Tratamento e transformação dos dados

Durante o desenvolvimento do projeto, os dados foram tratados no **Power Query**, incluindo etapas como:

- Organização e limpeza dos dados;
- Ajuste dos cabeçalhos das tabelas;
- Alteração dos tipos de dados;
- Tratamento das colunas utilizadas na análise;
- Preparação das tabelas para o modelo de dados;
- Integração da base de vendas com a base de metas.

## 📈 Análises realizadas

O projeto permite analisar informações relacionadas a:

- Vendas;
- Lucro;
- Regiões;
- Anos;
- Metas;
- Comparação entre resultados e metas.

Foram utilizados diferentes tipos de visualizações para apresentar os resultados de forma mais clara e facilitar a análise das informações.

## 📊 Dashboard

O relatório desenvolvido no Power BI apresenta os dados por meio de gráficos e indicadores, permitindo visualizar os principais resultados e realizar comparações entre diferentes períodos e regiões.

## 🎯 Objetivo acadêmico

O projeto teve como objetivo colocar em prática conceitos de análise e tratamento de dados, além de desenvolver conhecimentos relacionados ao Power BI, Power Query, linguagem M, DAX e modelagem de dados.
